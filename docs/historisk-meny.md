# Historisk meny som kategorigrunnlag

Et skjermbilde fra Internet Archive av HadselPortalen i 2001 brukes som inspirasjon til dagens informasjonsarkitektur. Den skjulte fanen mellom `Magasinet` og `Gjestebok` var `Debatt`.

## Horisontal meny

| Historisk menypunkt | Dagens bruk |
| --- | --- |
| Hovedside | Portalens forside, ikke kategori |
| Nyheter | Portalkategori og innhold under Aktuelt |
| Magasinet | Portalkategorien `Magasin` for lengre redaksjonelt stoff |
| Debatt | Portalkategori; publisering skal være redaktørstyrt |
| Gjestebok | Utgår; gir unødvendig spam- og modereringsarbeid |
| Annonser | Eventuell framtidig side eller annonseflate, ikke innholdskategori nå |
| Om Portalen | Fast informasjonsside |
| Kontakt | Fast kontaktside |

## Vertikal meny

De historiske temaene videreføres i modernisert form:

- `Hadsel`
- `Historie`
- `Næringsliv`
- `Kommunal informasjon`
- `Ferie og fritid`
- `Lag og foreninger`
- `Helse og miljø`
- `Friluftsliv` dekker historiske «Natur & Friluft»
- `Skole og barnehage`
- `Kultur` dekker historiske «Kunst & Kultur»
- `Mat og drikke`
- `Sport og spill`

Kategoriene beskriver tema. Stokmarknes, Melbu, Blokken, Hennes, Sandnes og Innlandet skal fortsatt behandles som steder, slik at brukerne kan kombinere tema- og stedsfiltre.
