# Legacy-kode

Denne mappen inneholder uendrede snapshots av kode hentet fra produksjon før videreutvikling.

## `hadsel-rss-0.2.0`

Hentet skrivebeskyttet fra:

```text
/www/hadselportalen/wp-content/plugins/hadsel-rss/
```

Snapshotet består av to PHP-filer og tilsvarer pluginversjon 0.2.0. Koden skal ikke redigeres eller distribueres tilbake til produksjon fra denne mappen. Den beholdes som referanse og rollback-grunnlag mens funksjonaliteten videreføres i `Lokalportalen Core`.
